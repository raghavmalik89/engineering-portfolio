# Website Roadmap

## Phase 0 - Foundation

Create repository structure, Codex agents, skills, tracker, architecture, and
decision log.

Status: Complete.

## Phase 1 - Website Architecture Foundation

Initialize the website application inside `website/`, create stable route
placeholders, establish component/content/data/lib/type boundaries, and verify
the scaffold builds.

Status: Complete.

## Phase 2 - Design System

Freeze the visual direction, design principles, color tokens, typography
direction, spacing, layout rules, component scope, motion rules, accessibility
requirements, imagery strategy, and implementation guardrails.

Status: Complete.

## Phase 3 - MVP Pages

Implement layout, navigation, footer, base components, and MVP pages using the
frozen design system.

## Phase 4 - First Flagship Case Study

Build the CC1310 custom industrial IoT sensor case study with public-safe
photos, diagrams, and engineering decisions.

## Phase 5 - Expand Technical Proof

Add SmartRoller, GET Vision, Proton Therapy, Space Electronics, and Robotics
pages.

## Phase 6 - Authority Layer

Expand Engineering Decisions and Engineering Notebook with public-safe technical
articles.

## Phase 7 - Deployment and Polish

Deploy to Vercel, add SEO metadata, optimize images, and polish visual details.
