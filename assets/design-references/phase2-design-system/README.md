# Phase 2 Design System References

This folder stores Phase 2 design reference images, mockups, AI-generated
concepts, wireframes, and visual inspiration.

These assets are reference material only. They are not production website
assets and should not be copied pixel-for-pixel into the website.

Implementation must follow `docs/DesignSystem.md`. Images in this folder capture
the approved visual direction from Phase 2 so future implementation work has a
shared reference point.

Production-ready design assets should go under `assets/design-system/` or the
relevant project, photo, or diagram folder.
